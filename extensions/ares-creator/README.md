# 🎬 ARES Creator Studio

A full-featured AI content creator and VTuber engine for ARES.

## Features

- **Live VTuber Avatar Overlay**: MediaPipe webcam face-mesh tracking driving 3D VRM models with a transparent OBS Browser Source URL (`/overlay/avatar`).
- **Hybrid Video Producer**: Generate full YouTube video scripts with hooks, scene breakdowns, visual prompts, and Remotion render configs.
- **Autonomous YouTube Learning**: Ingest any YouTube video by URL or ID, parse transcripts with `yt-dlp` / `youtube-transcript-api`, and index knowledge into agent memory.
- **ARES Tab HUD**: Intuitive three-tab creator workspace inside the ARES WebUI.
- **JaegerAI Tooling**: Agent can autonomously research videos and draft video scripts.
