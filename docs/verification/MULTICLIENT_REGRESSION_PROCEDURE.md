# Portable regression procedure — proposal, not a completed run

1. Import the exact source into a NEW empty isolated directory from the eventual baseline pack/shallow marker/incremental bundle. Verify all ordered parents, commit/tree and patch against recorded identities, without alternates. Do not use an existing runtime checkout. Resolve final bundle refs/docs head from the final manifest; this draft intentionally supplies no guessed import ref.
2. Use existing approved dependencies. Pin HOME, TMPDIR, all application state-root variables, bytecode and caches outside source to disposable synthetic directories. Preserve repository normal conftest. Record Python imports, versions, full command, environment allowlist, selectors, exits and machine-readable results. Never copy credentials, environment secrets, runtime databases or HOME into evidence.
3. Verify frozen evaluator/contract hashes. Run the original oracle on its recorded baseline and candidate with independently reviewed thin adapters. Retain baseline failures and all setup errors separately.
4. Run normal-conftest unified API, Studio concurrency and Document persistence tests. Exercise valid/missing/malformed/stale preconditions; legacy exact bytes; missing creation; invalid schema, read denial and post-load corruption preservation; ABA; current-base ordered save/reopen. Assert rejected bytes are unchanged.
5. Run repeated independent PROCESS contenders at one base; verify at most one commits, canonical symlink aliases/different operator state roots share locking and fresh processes reopen the exact winner. Exercise unique replacement/fault behavior. Do not monkeypatch the decision or writer to simulate correctness.
6. Interleave asset deletion and Board edits using only synthetic assets. Verify current unrelated notes survive, stale references cannot resurrect and corrupt/read-denied Board prevents asset/index side effects. Record partial deletion crash limitations honestly.
7. Mount two independent real Board roots. Route through actual producer/disk subprocesses in the independent integration control; keep mocked CAS controls labeled. First commit succeeds; stale second commit rejects without disk change while preserving draft and original base. Edit again and advance timers past debounce/toast duration: persistent warning, no replay. Verify acknowledgment normalization, coalesced saves, malformed/unknown outcomes, failed load and source/lifetime guards.
8. Run complete UI/typecheck with matching sibling IDE/media declarations, production build and normal scripts/verify.sh separately. Include fresh changed-helper consumer and broader backend gates. Explicitly record browser/attached-client deselections, unavailable AF_UNIX/native paths and any failed/skipped tests. No bypass of access restrictions.
9. Build root wheel/sdist. Validate tracked source/runtime deltas, complete compiled UI hashes/bytes, RECORD and archive safety. Reuse eight companions only after exact 1,950 inputs, package-tree and archive hashes match. Keep only the explicitly documented three source-only README exclusions.
10. Curate commands, probes, adapters, raw machine results and logs through an allowlist with original and sanitized SHA256 for every derivative. Recheck source cleanliness/identity after tests. Independently review the later exact ZIP and import evidence before authorized publication. Gate PASS is not deployment or whole-product PASS.
