## When to use - User asks to "standardize", "clean up formatting", "make it match the other tabs", or "audit and fix formatting" on any analysis tab - User invokes `/standardize-tab` on a specific sheet - After building a new tab, to bring it into spec with the rest of the workbook ## Workflow ### Step 1 — Read the tab (read-only) 1. Read the full tab with `get_cell_ranges` (includeStyles: true) in chunks if needed 2. Read the USFS tab rows 1–5 as the formatting reference (title bar, subtitle, flow path, table index) 3. Compare every element against the spec below 4. **List all proposed changes** in chat — grouped by category (colors, fonts, borders, wrap, merges, verdict rows, notional cells, calculation notes) 5. **Do NOT make any changes yet** — wait for user confirmation ### Step 2 — Fix after confirmation Apply changes in logical order: 1. Title bar / header rows (rows 1–4) 2. Section headers 3. Sub-headers (column labels) 4. Data row formatting (alternating, fonts, colors) 5. Borders 6. Wrap text & row heights 7. Merges (where applicable) 8. **Green verdict/conclusion bars** ← MANDATORY — see spec below 9. **Notional cell highlighting** ← MANDATORY — see spec below 10. **Calculation validation column** ← MANDATORY — see spec below 11. Cross-sheet link fixes 12. Verify formulas after all formatting changes Done when: every cell matches the spec, wrap text is correct, merges are applied where needed, green verdict bars exist on all summary/conclusion rows, notional cells are highlighted yellow with amber borders, every calculated cell has a what/why/how entry in the Calculation Notes column, and a re-read confirms no regressions. --- ## Formatting Spec ### Header Rows (rows 1–4) - **Row 1** — Title: bold, white `#FFFFFF`, dark blue `#1F4E79` fill. Merged full width. - **Row 2** — Subtitle: italic, white `#FFFFFF`, `#2E4057` fill. Merged. - **Row 3** — Flow path: bold, `#1F4E79` text, `#D6E4F0` fill. Merged. - **Row 4** — Table index: regular, `#2E4057` text, `#EBF3FB` fill. Merged. - Match existing structure — don't force rows that aren't there. ### Section Headers - Bold, white `#FFFFFF`, `#2E75B6` fill, merged full data width ### Sub-Headers (column labels) - Bold, black `#000000`, `#BDD7EE` fill, thin `#D0D0D0` bottom border ### Data Rows - Alternating white `#FFFFFF` / pale blue `#F2F7FC` - Calibri 14pt (wide tabs) or 11pt (narrow tabs) - Inputs: bold, blue `#0000FF` - Cross-sheet links: green `#008000` - Formulas: black `#000000` ### ⚠ Green Verdict Bars (MANDATORY — DO NOT SKIP) Every table/section must end with a verdict row (unless pure reference/lookup). - Bold, dark green `#375623` text, light green `#E2EFDA` fill, merged full width - Pattern: `VERDICT: [finding] — [number] [emoji]. Required: [action] (OI-0XX).` - One paragraph. Lead with finding, cite numbers, name blocker. No hedging. - Identify by: "VERDICT:", "SELECTED:", "CONCLUSION:", "RECOMMENDATION:", or summary text that concludes a section - If a section has no verdict row and one is needed, flag it in proposed changes — don't create content without asking ### ⚠ Yellow Notional Cells (MANDATORY — DO NOT SKIP) Any placeholder, notional assumption, or unverified value must be highlighted. - Bold, amber `#7F6000` text, yellow `#FFFF00` fill - **Medium amber `#7F6000` border on all four sides** — distinguishes notional cells from the thin `#D0D0D0` internal grid at a glance - Identify by: notes saying "Notional", "TBD", "verify", "assumed", "estimate"; model-derived estimates; design assumptions not validated by test; assumed S/C parameters - Do NOT highlight: verified requirements (PDC-XXX), established constants (g₀), measured values, formula cells

### ⚠ Calculation Validation Column (MANDATORY — DO NOT SKIP) Every calculated cell must have a corresponding entry in a **"Calculation Notes"** column documenting what/why/how. - If the tab has no Calculation Notes column and calculations exist, flag it in proposed changes and recommend adding one (don't add silently) - Format: same data row styling, wrap text ON, Calibri (not Courier — that's the equations column) - Each entry covers three things in one cell, on separate lines: - **What**: what quantity is being computed (e.g., "Delta-V budget for Hohmann transfer") - **Why**: why this calculation matters (e.g., "Required to size propellant tank per OI-042") - **How**: the method/source (e.g., "Vis-viva equation; r₁, r₂ from PDC-101; μ_earth = 3.986e14") - If a calculated cell is missing what/why/how, flag it in proposed changes — do NOT invent justifications. Ask the user. - Cross-sheet referenced values count as calculations and need entries (e.g., "Pulled from PROPELLANT PROPERTIES!B12 — Isp at vacuum") ### Borders - Internal grid: thin `#D0D0D0` - Left + right outer edges: thin `#2F5496` ### Equations Column - `Courier New` font (not Calibri), same size as data rows ### RAG Colors - 🟢 `#00B050` — safe / met - 🟡 `#FFFF00` — caution / marginal - 🔴 `#FF0000` — exceeds limit / violated ### Wrap Text - ON for data cells, verdict rows, notes columns - OFF for numeric-only cells and row 1 title - Autofit row heights after enabling ### Merges - Merge: title rows, section headers, verdict rows, narrative text with empty adjacent cells - Do NOT merge: formula cells, column headers, cells with content - Always read target range before merging to confirm adjacent cells are empty --- ## Content Checks - Every hardcoded number that exists elsewhere in the workbook → should be a cross-sheet formula reference - Every input assumption → blue text, labeled - Every table → has a verdict/conclusion row in green (unless reference/lookup) - **Every notional/placeholder value → yellow highlight + amber border with amber text** - **Every calculated cell → has a what/why/how entry in the Calculation Notes column** - Units stated in headers or a dedicated column - Verify formula results — check for `#VALUE!`, `#REF!`, `#NAME?`, `#DIV/0!` ## DO NOT: - Change any cell values or restructure the tab layout without explicit user approval - Delete or clear rows/columns without listing what's there first - Touch rows/columns that already match the spec - Break existing formulas or cross-sheet links - Apply formatting to cells you haven't read first
