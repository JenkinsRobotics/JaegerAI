32 GB Apple Silicon Discipline

Three priority tiers keep one machine aware 24/7.

Enforced in-process by jaeger_orchestration.ResourceGovernor — max one heavy model resident at a time, instant SQLite WAL preemption, and hard-pruned camera frame buffers.

TIER 1 · HIGHEST

OWNER_WORK

Instantly preempts idle background tasks and reserves the single heavy model slot (LLM or VLM, never both simultaneously) for interactive coding, research, or studio production.

TIER 2 · ALWAYS-ON

AWARENESS_SAFETY

Lightweight 24/7 Kokoro MLX TTS, Whisper STT, rolling-pruned camera buffer (max 6 resident frames), and hardware/software L2 E-Stop latch.

TIER 3 · BACKGROUND

IDLE_LIFE

When the owner is away and RAM headroom is healthy, pursues persistent multi-day goals (such as headless Minecraft co-op at ~150 MB RAM / 0 GPU) with instant checkpointing on return.

Quick Start

Install on macOS, Linux, or Windows in minutes.

Choose portable Jaeger Core (Python 3.11–3.12 only, zero Node.js/MLX required) or the full macOS source checkout.

Option A — Portable Jaeger Core (macOS Apple Silicon & Intel · Linux · Windows x64)
# 1. Download & extract jaeger-core-1.0.1.zip from GitHub Releases
#    https://github.com/JenkinsRobotics/JaegerAI/releases/latest

# 2. Install into ~/.jaeger/core-venv (macOS / Linux):
python3 install-core.py

#    Or on Windows (PowerShell):
py -3.12 install-core.py

# 3. Run the exact launch command printed by the installer, then open:
http://127.0.0.1:8790
Option B — Full macOS / Linux Source Setup (32 GB Apple Silicon Stack)
# Clone and run reproducible setup (profiles: core | business | companion | droid | full)
git clone https://github.com/JenkinsRobotics/JaegerAI.git
cd JaegerAI
./install.sh --profile full

# Verify packages, binaries, WebUI build, and live Gateway
./jaeger doctor

# Start Gateway (:33418) + 5-Tab Studio WebUI (:8790) and open in browser
./jaeger start
./jaeger open

# Run full backend + AST layering + frontend Vitest + external Vite verification
./jaeger verify
